이용약관

1. 앱의 기능

방구리퐁퐁은 Windows에서 YouTube 채널 연결, 영상 업로드와 공개 예약, 채널 실적 조회를 지원합니다. 이 앱은 YouTube API 서비스를 이용하며, 앱을 사용하면 YouTube 서비스 약관의 적용을 받습니다.

2. 채널과 영상 권한

관리 권한을 가진 채널을 연결하고, 게시할 권리가 있는 영상과 자료를 사용해야 합니다. 업로드 전에 채널과 공개 범위, 예약 날짜와 시간대를 확인하세요.

3. 업로드 상태와 조회 결과

영상 처리와 공개 예약은 YouTube의 처리 상태와 채널 권한에 따릅니다. 업로드 이후 실제 공개 범위와 예약 상태는 해당 채널의 YouTube Studio에서 확인할 수 있습니다. 예상 수익은 YouTube Analytics에서 제공하는 집계값이며 업데이트될 수 있습니다.

4. 개인정보와 문의

권한 범위와 데이터 처리, 연결 해제 방법은 개인정보처리방침에서 확인할 수 있습니다.

개인정보 처리, 데이터 삭제 또는 앱 이용에 관한 문의는 Google에서 방구리퐁퐁 연결을 시작할 때 표시되는 승인 화면의 사용자 지원 이메일로 보낼 수 있습니다.
