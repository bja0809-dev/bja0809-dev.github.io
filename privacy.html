개인정보처리방침

이 방침은 Windows 앱 방구리퐁퐁의 Google 연결과 YouTube API 서비스 이용에 적용됩니다. Google 서비스 자체의 개인정보 처리 방식은 Google 개인정보처리방침을 참조하세요.

1. 접근하는 정보와 이용 목적

  • 계정 연결 및 채널 식별. Google에서 발급한 OAuth 토큰과 YouTube 채널 ID, 이름, 프로필 이미지 정보를 사용해 사용자가 허용한 채널을 식별하고 연결을 유지합니다. Google 로그인은 Google에서 처리하며, 앱은 Google 비밀번호를 수집하거나 저장하지 않습니다.
  • 영상 전송 및 결과 확인. 사용자가 지정한 영상 파일, 썸네일, 제목, 설명, 공개 범위, 예약 설정을 YouTube에 전송합니다. YouTube가 반환한 영상 ID와 처리 상태로 결과를 확인합니다.
  • 실적 조회. 채널 또는 영상의 조회수, 구독자 수 등 운영 지표를 화면에 표시합니다. 사용자가 별도로 수익 조회 권한을 허용하면 YouTube Analytics에서 제공하는 예상 수익 등 수익 지표를 조회합니다.

2. 저장, 처리 및 공유

Google OAuth 인증 정보와 진행 중인 업로드 세션은 이 앱을 실행하는 Windows 사용자의 로컬 저장소에 보관합니다. 인증 정보는 Windows의 사용자별 암호화 기능으로 보호합니다. 채널 목록, 앱 설정, 조회 결과와 작업 기록은 앱의 저장 경로에 남을 수 있습니다. 사용자가 Google Drive를 작업 경로로 사용하면 작업 파일과 일부 설정이나 작업 기록이 해당 Drive를 통해 동기화될 수 있습니다.

Google 연결, YouTube 영상 전송, 통계 조회에는 Google과 YouTube가 제공하는 서비스를 사용합니다. Google 사용자 데이터는 사용자가 사용하는 기능에 필요한 범위에서 처리하며, 판매하거나 광고 목적으로 이용하지 않습니다. Google API로 받은 정보의 이용 및 전송에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건이 적용됩니다.

이 안내 사이트는 계정 연결 양식이나 광고·분석용 스크립트를 제공하지 않습니다. 호스팅 제공업체는 사이트 운영과 보안을 위해 방문 요청을 처리할 수 있습니다.

3. 연결 해제와 데이터 삭제

앱의 계정 연결에서 채널을 선택한 뒤 선택 계정 연결 해제를 사용해 앱에서 해당 연결을 해제할 수 있습니다. Google이 부여한 접근 권한은 Google 계정의 서드 파티 연결 설정에서 방구리퐁퐁을 선택해 철회할 수 있습니다.

연결 해제 후에도 앱의 채널 목록, 작업 기록 및 사용자가 선택한 작업 경로의 파일이 남을 수 있습니다. 해당 자료의 삭제가 필요하면 아래 지원 연락처로 요청할 수 있습니다. YouTube에 전송한 영상은 YouTube Studio에서 별도로 관리합니다.

4. 문의

개인정보 처리, 데이터 삭제 또는 앱 이용에 관한 문의는 Google에서 방구리퐁퐁 연결을 시작할 때 표시되는 승인 화면의 사용자 지원 이메일로 보낼 수 있습니다.
